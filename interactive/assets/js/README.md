# Shared JavaScript assets

These scripts are loaded by the static lesson pages in `interactive/`.

- `core.js` provides shared navigation, page controls, plotting helpers, and the `MD.lab` interface used by interactive lessons.
- `physics.js` contains the course's shared molecular-dynamics potentials, integrators, and numerical helpers.
- `water.js` provides the shared water-model engine used by Modules 9 and 12, including electrostatics, rigid-water constraints, and analysis helpers.

Keep reusable lesson code here; module-specific explanations and markup belong in the corresponding HTML page.
