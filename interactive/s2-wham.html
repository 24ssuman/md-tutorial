Part 1Review: PMF and Probability

Let $x$ be a reaction coordinate (collective variable). The potential of mean force (PMF) is defined from the equilibrium probability density $P(x)$:

$$F(x) = -k_BT\ln P(x) + C.$$

For a true 1D system with potential energy $U(x)$ at temperature $T$,

$$P(x) \propto e^{-\beta U(x)}\quad (\beta = 1/(k_BT)),$$

so the PMF differs from $U(x)$ only by an additive constant.

Beyond 1D

In real molecular systems (many hidden degrees of freedom), $F(x)$ is a free energy, not just the potential energy.

Part 2Define a Toy Double-Well System

We choose a symmetric double-well potential:

$$U(x) = a\,(x^2-1)^2.$$

This has two minima near $x=\pm 1$ separated by a barrier near $x=0$.

📝 Plain-English steps of the WHAM derivation

The WHAM derivation can look mathematically intimidating, but it is built on simple principles:

1

Probability density

In each window $i$, the probability of finding a particle in bin $j$ depends on the true unbiased probability ($P_j$) and the known bias potential factor ($e^{-\beta w_{i,j}}$).

2

Histogram counts

We write the expected count in bin $j$ for window $i$ as a function of the total window samples ($n_i$) and the biased probability.

3

Optimal estimator

We combine all histograms using a weighted average that minimizes the statistical variance.

4

Self-consistency

The resulting equations depend on free energy offsets ($f_i$) which themselves depend on the unbiased probabilities ($P_j$). We solve this circular loop by iterating until the free energies stop changing.

Part 3Umbrella Bias Potentials

Umbrella window $i$ adds a harmonic bias centered at $x_{0,i}$:

$$w_i(x) = \tfrac{1}{2}k(x-x_{0,i})^2.$$

That window samples the biased distribution

$$P_i(x) \propto e^{-\beta[U(x)+w_i(x)]}.$$

A key WHAM assumption is that windows have overlap in $x$ so the method can stitch them together.

Umbrella parameters; plot biases and biased potentials

Part 4Generating Synthetic Umbrella Data

To keep the focus on WHAM (not dynamics), we generate independent samples from each biased distribution $P_i(x)$.

We will:

  • choose WHAM bins,
  • draw $n_i$ samples per window,
  • build the histogram counts $N_{ij}$.
Bin, sample each window, and build N_ij
# WHAM binning
n_bins = 120
bin_edges = np.linspace(x_min, x_max, n_bins + 1)
bin_centers = 0.5 * (bin_edges[1:] + bin_edges[:-1])

# Sample counts per window
n_per_window = 5000

# Precompute biased probability mass per bin for sampling
# (integrate P_i(x) over each bin approximately via the grid)

bin_index = np.clip(np.digitize(x_grid, bin_edges) - 1, 0, n_bins - 1)

Pmass = np.zeros((num_windows, n_bins))
for i in range(num_windows):
    for j in range(n_bins):
        mask = bin_index == j
        Pmass[i, j] = np.sum(P_biased[i, mask]) * dx
    Pmass[i] /= np.sum(Pmass[i])

# Draw samples by first choosing a bin then uniformly within the bin
samples = []
for i in range(num_windows):
    chosen_bins = rng.choice(n_bins, size=n_per_window, p=Pmass[i])
    x_lo = bin_edges[chosen_bins]
    x_hi = bin_edges[chosen_bins + 1]
    x_samp = x_lo + rng.random(n_per_window) * (x_hi - x_lo)
    samples.append(x_samp)

n_i = np.array([len(s) for s in samples], dtype=int)

# Histogram counts N_ij
N_ij = np.zeros((num_windows, n_bins), dtype=int)
for i in range(num_windows):
    N_ij[i], _ = np.histogram(samples[i], bins=bin_edges)

# Plot window histograms (densities)
bin_width = bin_edges[1] - bin_edges[0]
plt.figure(figsize=(7, 4))
for i in range(num_windows):
    dens = N_ij[i] / (n_i[i] * bin_width)
    plt.plot(bin_centers, dens, alpha=0.65)
plt.xlabel('x')
plt.ylabel('density (biased)')
plt.xlim(-2,2)

Overlap diagnostic

A compact overlap metric between window histograms is

$$\mathrm{BC}(i,k)=\sum_j \sqrt{p_{ij}p_{kj}},$$

where $p_{ij}$ is the histogram probability mass in bin $j$ for window $i$.

Overlap matrix and nearest-neighbour summary
p_ij = np.zeros_like(N_ij, dtype=float)
for i in range(num_windows):
    if n_i[i] > 0:
        p_ij[i] = N_ij[i] / np.sum(N_ij[i])

BC = np.zeros((num_windows, num_windows), dtype=float)
for i in range(num_windows):
    for k in range(num_windows):
        if np.sum(p_ij[i]) > 0 and np.sum(p_ij[k]) > 0:
            BC[i, k] = np.sum(np.sqrt(p_ij[i] * p_ij[k]))

plt.figure(figsize=(6.2, 5.2))
plt.imshow(BC, origin='lower', vmin=0, vmax=1, cmap='viridis')
plt.colorbar(label='histogram overlap')
plt.title('Window overlap (higher is better)')
plt.xlabel('window')
plt.ylabel('window')
plt.tight_layout()
plt.show()

if num_windows >= 2:

Exercise — why is the minimum nearest-neighbour overlap so much lower than the median?

The Python run prints min=0.085, median=0.841, max=0.899. Hover over the overlap matrix in the lab above to find which neighbour pair is the weak link, and look at where those two windows are centred.

Answer

The weak pair is the two central windows, centred just either side of the barrier at $x = \pm 0.18$. With $a = 10$ the barrier top is strongly curved downward ($U''(0) = -4a = -40$), and a $k = 30$ umbrella cannot overcome that: $U + w_i$ is still a double well, so each central window slides off the barrier toward “its” side and the two hardly share any bins. Conversely, the outer windows ($x_0 = \pm 1.24, \pm 1.6$) are all pulled into the same steep well near $x \approx \pm 1$, so they overlap very strongly — that is why the median is high. A stiffer spring (try $k = 60$–$100$) pins the central windows on the barrier and evens out the overlap.

Part 5The WHAM Equations

WHAM is easiest to understand if we separate three ideas:

  1. What each window samples (biased ensemble)
  2. What we want (the unbiased $P(x)$ or PMF)
  3. How WHAM combines windows optimally (self-consistent normalization)

Biased vs unbiased probability

Unbiased equilibrium probability density:

$$P(x)=\frac{e^{-\beta U(x)}}{Z}, \qquad Z=\int dx\,e^{-\beta U(x)}.$$

Umbrella window $i$ adds bias $w_i(x)$, so the biased density is

$$P_i(x)=\frac{e^{-\beta[U(x)+w_i(x)]}}{Z_i}, \qquad Z_i=\int dx\,e^{-\beta[U(x)+w_i(x)]}.$$

Histogram binning

We bin $x$ into bins $j=1,\dots,N_{\mathrm{bins}}$ with centers $x_j$ and width $\Delta x$. From window $i$ we measure histogram counts $N_{ij}$ and total samples $n_i=\sum_j N_{ij}$.

Define the reduced bias in bin $j$:

$$u_{ij} \equiv \beta w_i(x_j).$$

We estimate the unbiased probability mass per bin

$$P_j \approx \int_{\text{bin }j} dx\,P(x), \qquad \sum_j P_j = 1.$$

(If you want a density, use $p(x_j)\approx P_j/\Delta x$.)

Self-consistent WHAM equations

WHAM solves for $\{P_j\}$ and per-window constants $\{f_i\}$ (in units of $k_B T$). The coupled equations are:

$$\boxed{\;P_j = \frac{\sum_i N_{ij}}{\sum_i n_i\exp\!\left(f_i-u_{ij}\right)}\;}$$

and

$$\boxed{\;e^{-f_i}=\sum_j P_j e^{-u_{ij}}\;}$$

Notes:

  • The numerator $\sum_i N_{ij}$ is the total counts in bin $j$ across windows.
  • The denominator reweights those counts by the window bias at $x_j$.
  • $f_i$ is defined up to an additive constant; we set $f_0=0$.

Recovering the PMF

Once $P_j$ is known, the reconstructed PMF is

$$F(x_j)=-k_B T\ln P_j + C,$$

where $C$ is arbitrary (we shift the minimum to 0 for plotting).

run_wham: the self-consistent iteration
import warnings

def run_wham(N_ij, n_i, u_ij, max_iter=20000, tol=1e-8):
    '''Return (P_j, f_i, delta_f_hist).'''
    N_ij = np.asarray(N_ij)
    n_i = np.asarray(n_i)
    u_ij = np.asarray(u_ij)

    n_win, n_bins = N_ij.shape

    # init
    f_i = np.zeros(n_win)
    P_j = np.sum(N_ij, axis=0).astype(float)
    if np.sum(P_j) <= 0:
        raise ValueError('No counts in any bin.')
    P_j /= np.sum(P_j)

    delta_hist = []

    for it in range(max_iter):
        f_old = f_i.copy()

        # Update P_j
        denom = np.sum(n_i[:, None] * np.exp(f_i[:, None] - u_ij), axis=0)
        numer = np.sum(N_ij, axis=0)

        P_new = np.zeros_like(P_j)
        ok = denom > 1e-300
        P_new[ok] = numer[ok] / denom[ok]

        s = np.sum(P_new)
        if s <= 0:
            raise RuntimeError('WHAM collapsed: sum(P_new) <= 0 (likely zero overlap).')
        P_j = P_new / s

        # Update f_i
        with warnings.catch_warnings():
            warnings.simplefilter('ignore', category=RuntimeWarning)
            Z_i = np.sum(P_j[None, :] * np.exp(-u_ij), axis=1)
            f_i = -np.log(Z_i)

        f_i -= f_i[0]

        delta = float(np.max(np.abs(f_i - f_old)))
        delta_hist.append(delta)
        if delta < tol:
            break

    return P_j, f_i, np.array(delta_hist)

# Reduced bias energies u_ij = beta*w_i(x_j)
u_ij = np.zeros((num_windows, n_bins))
for i, x0 in enumerate(centers):
    u_ij[i] = beta * w_i(bin_centers, x0)

P_wham, f_wham, delta_hist = run_wham(N_ij, n_i, u_ij, max_iter=5000, tol=1e-10)
print('WHAM iterations:', len(delta_hist))
print('max |Δf| final:', delta_hist[-1])
WHAM iterations: 2338
max |Δf| final: 9.970335668185726e-11

Watch the iteration, step by step

The loop in run_wham starts from $f_i = 0$ (so the first $P_j$ is just the pooled histogram, still full of bias) and alternates between the two boxed equations. Scrub through the iterations (or press Play) to see the PMF estimate, the offsets $f_i$ and the convergence trace evolve together.

Why does run_wham set f_i -= f_i[0] every iteration?

  1. Because window 0 is always the most reliable window
  2. The $f_i$ are only defined up to a common additive constant, so one must be pinned (here $f_0 = 0$)
  3. To make the PMF minimum equal to zero
Adding the same constant to every $f_i$ leaves the normalized $P_j$ unchanged, so the equations cannot determine it. Fixing $f_0 = 0$ removes that freedom and makes $\max|\Delta f_i|$ a meaningful convergence measure. (Shifting the PMF minimum to zero is a separate, cosmetic choice made when plotting.)

Part 7How WHAM Stitches Windows

One way to see the stitching is to look at the fractional contribution of each window to each bin's denominator:

$$c_{ij}=\frac{n_i\,\exp(f_i-u_{ij})}{\sum_k n_k\,\exp(f_k-u_{kj})}.$$

For a given $x_j$, WHAM mostly trusts the windows whose umbrellas actually sample that region.

Window contribution fractions c_ij
weights = n_i[:, None] * np.exp(f_wham[:, None] - u_ij)

Exercise — break WHAM, then fix it
  1. Press Too few windows. Where do gaps appear in the histograms and in the overlap matrix? What happens to the PMF and the convergence trace?
  2. Press Stiff springs ($k = 300$). Ten windows are still there — why does it fail anyway?

What to look for

Each failure shows up first in the diagnostics: zero entries on the first off-diagonal of the overlap matrix and empty bins between windows. WHAM then has no data to fix the relative offsets $f_i$ of the disconnected pieces, so the PMF splits into segments shifted by arbitrary amounts, and the convergence trace either stalls or “converges” to a meaningless answer. Stiff springs fail because each window becomes very narrow ($\sigma \approx \sqrt{k_BT/(k + U'')}$), so ten of them can no longer tile the interval. Adding windows or softening $k$ until neighbours overlap again restores the reconstruction — the practical workflow above, in action.

📝 Key Takeaways

  • WHAM is a self-consistent iterative solver that estimates the unbiased probability density and free energy offsets simultaneously.
  • The convergence is reached when the maximum change in free energy offsets ($f_i$) between successive iterations falls below a tolerance (e.g., $10^{-8}$).
  • WHAM is highly sensitive to the quality of window overlap and bin resolution.

In the contribution map $c_{ij}$, a bin at the barrier top gets roughly 50% from each of two windows. What does that mean?

  1. Both windows sample that bin, so WHAM averages their (reweighted) information there — this is where the stitching happens
  2. The two windows disagree, so WHAM throws that bin away
  3. Half of the samples in that bin are duplicates
$c_{ij}$ is each window's share of the denominator in bin $j$. Regions where two windows share the weight are exactly the overlap regions that tie neighbouring $f_i$ together.
