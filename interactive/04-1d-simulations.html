Lesson 1Harmonic Oscillator (NVE)

The Simple Harmonic Oscillator (SHO) is a fundamental model in physics. It describes a system where the restoring force is directly proportional to the displacement from an equilibrium position. Think of a mass attached to a spring.

Potential energy

For a 1D SHO:

$$V(x) = \frac{1}{2}kx^2$$

where $k$ is the spring constant (stiffness) and $x$ is the displacement from equilibrium ($x=0$).

Force

The force is the negative derivative of the potential:

$$F(x) = -\frac{dV}{dx} = -kx$$

The negative sign means the force is restoring, always pulling the particle back toward $x=0$.

We will simulate this system in the microcanonical (NVE) ensemble, where total energy (kinetic + potential) should be conserved up to numerical integration error.

What's inside these md_tutorial functions? (condensed source) 
def potential_sh(x, k):
    return 0.5 * k * x**2

def force_sh(x, k):
    return -k * x

def velocity_verlet_step(x_curr, v_curr, mass, dt, force_func, **force_args):
    f_curr = force_func(x_curr, **force_args)
    a_curr = f_curr / mass

    v_half = v_curr + 0.5 * a_curr * dt     # 1. half-step velocity
    x_new = x_curr + v_half * dt            # 2. full-step position

    f_new = force_func(x_new, **force_args) # 3. new force at x(t + dt)
    a_new = f_new / mass

    v_new = v_half + 0.5 * a_new * dt       # 4. second half-step velocity
    return x_new, v_new

Solution: the NVE simulation loop
# --- NVE Simulation Loop ---

# Arrays to store results
times = np.zeros(n_steps)
positions = np.zeros(n_steps)
velocities = np.zeros(n_steps)
kinetic_energies = np.zeros(n_steps)
potential_energies = np.zeros(n_steps)
total_energies = np.zeros(n_steps)

# Set initial values
positions[0] = x0
velocities[0] = v0

# Calculate initial energies
kinetic_energies[0] = 0.5 * mass * velocities[0]**2
potential_energies[0] = potential_sh(positions[0], k=k_sh)
total_energies[0] = kinetic_energies[0] + potential_energies[0]

# Run the simulation loop
for i in range(n_steps - 1):
    # Perform one Verlet step
    x_new, v_new = velocity_verlet_step(
        positions[i], velocities[i], mass, dt, force_sh, k=k_sh
    )

    # Store new values
    positions[i+1] = x_new
    velocities[i+1] = v_new
    times[i+1] = times[i] + dt

    # Calculate and store energies for the new state
    kinetic_energies[i+1] = 0.5 * mass * v_new**2
    potential_energies[i+1] = potential_sh(x_new, k=k_sh)
    total_energies[i+1] = kinetic_energies[i+1] + potential_energies[i+1]

print("NVE Simulation finished.")

The core MD loop

Every MD code — from this 1D toy to a million-atom protein simulation — repeats the same three things: (1) compute forces from the current positions, (2) advance positions and velocities with the integrator, (3) record observables (here: positions, velocities and energies).

Energy is conserved, so $\frac{1}{2}v^2 + \frac{1}{2}x^2 = \frac{1}{2}$ — a circle of radius 1 (an ellipse when $k \ne m$). An inward or outward spiral would mean energy is being lost or gained, which is what a thermostat (or a poor integrator such as explicit Euler, which spirals outward) does.

Lesson 2Temperature Control with Langevin Dynamics

In the NVE simulation, total energy is conserved but temperature fluctuates. To sample the canonical ensemble, we add friction and random forces to Newton's law:

$$m\ddot{x} = F_{\rm phys}(x) - \gamma m\dot{x} + R(t), \qquad \langle R(t)R(t')\rangle = 2m\gamma k_B T_0\,\delta(t-t').$$

Integration scheme (modified Velocity Verlet)

1

Half-step velocity (physical force)

$$v \leftarrow v + \frac{F_{\rm phys}(x)}{m}\frac{\Delta t}{2}$$
2

Half-step position

$$x \leftarrow x + v\frac{\Delta t}{2}$$
3

Full-step velocity (friction + random)

$$c_1 = e^{-\gamma\Delta t}, \quad c_2 = \sqrt{\frac{k_B T_0}{m}(1-c_1^2)}$$ $$v \leftarrow c_1v + c_2\,\mathcal{N}(0,1)$$

where $\mathcal{N}(0,1)$ is a standard normal random variable.

4

Second half-step position

$$x \leftarrow x + v\frac{\Delta t}{2}$$
5

Second half-step velocity (physical force)

$$v \leftarrow v + \frac{F_{\rm phys}(x)}{m}\frac{\Delta t}{2}$$

These five sub-steps are the BAOAB splitting: B = velocity kick from the force, A = position drift, O = the thermostat (friction + noise, solved exactly over $\Delta t$).

Instantaneous temperature (1D)

$$T = \frac{mv^2}{k_B}$$

(Here we take $k_B=1$ in reduced units.)

Temperature and Langevin integrator

Let's define the temperature calculation function and the BAOAB integration step.

Instantaneous temperature and the Langevin (BAOAB) integrator
# Assume Boltzmann constant k_B = 1 for simplicity in reduced units
k_B = 1.0

def calculate_temperature_1d(velocity, mass):
  """Calculates instantaneous temperature for a 1D particle (kB=1)."""
  if mass <= 0:
      return 0.0 # Avoid division by zero if mass is invalid
  kinetic_energy = 0.5 * mass * velocity**2
  # For 1D, N_df = 1. KE = 0.5 * N_df * kB * T => T = 2 * KE / (N_df * kB)
  temperature = 2.0 * kinetic_energy / (1.0 * k_B)
  return temperature

Play along: the Langevin thermostat, live

In the NVT (Langevin) run, the total energy $E_K + V$ wanders up and down instead of staying constant. Why?

  1. The time step is too large, so the integrator is inaccurate
  2. The harmonic potential does not conserve energy
  3. The friction removes energy and the random kicks add it — the system exchanges energy with the heat bath
In NVT the thermostat plays the role of a heat bath. Friction ($-\gamma m\dot{x}$) drains energy, the random force $R(t)$ injects it, and on average they balance at the target temperature — but the instantaneous energy fluctuates. Run the same system without the thermostat (NVE) and the energy is flat.

You increase the friction coefficient $\gamma$ from 0.1 to 10. What happens?

  1. The particle couples more strongly to the heat bath: velocities relax toward the target temperature faster (on a time scale of about $1/\gamma$)
  2. The average temperature rises above the target $T_0$
  3. The thermostat switches off and the run becomes NVE
$\gamma$ sets the coupling strength: velocities forget their past in a time $\sim 1/\gamma$. The average temperature is still $T_0$ for any $\gamma > 0$, because $c_2$ is chosen to balance the friction (fluctuation–dissipation). Very large $\gamma$ does make the motion sluggish and over-damped — look at how the phase-space cloud is explored.

Lesson 3The Double-Well Potential

Now let's consider a more interesting potential: the double-well potential. This potential has two stable minima separated by an energy barrier. It is a simple model for systems that can exist in two different states (for example, conformational changes or reaction-like transitions).

Potential energy

A common form is:

$$V(x) = ax^4 - bx^2$$

where $a>0$ and $b>0$.

  • The $x^4$ term dominates at large $|x|$, confining the particle.
  • The $-x^2$ term creates two off-center minima.

Stationary points

The stationary points satisfy:

$$\frac{dV}{dx} = 4ax^3 - 2bx = 0$$

So we get $x=0$ (barrier top) and $x=\pm\sqrt{\frac{b}{2a}}$ (minima).

Barrier height

The barrier height relative to the minima is:

$$E_{\rm barrier} = V(0) - V\!\left(\pm\sqrt{\frac{b}{2a}}\right) = \frac{b^2}{4a}$$

Force

$$F(x) = -\frac{dV}{dx} = -\left(4ax^3 - 2bx\right) = -4ax^3 + 2bx$$

We will simulate this system in the NVE ensemble and ask whether the particle can cross the barrier within the simulation time.

💬 Discussion: energy vs. barrier height

How does the particle's behavior depend on its initial total energy relative to the barrier height? What would happen if the initial energy was much lower than the barrier? What if it was significantly higher? (Feel free to change v0_dw and re-run the simulation — in the panel above, that is the v₀ slider.)

This illustrates the sampling problem: if energy barriers are high relative to the system's energy/temperature, transitions between states (wells) become rare events that are difficult to observe in a standard MD simulation of limited length.

What you should find
  • $E_0$ below the barrier top ($E_0 < 0$ here): the particle oscillates inside its starting well forever. The phase-space orbit is a single closed loop around $x = -\sqrt{2}$; the other well is never visited, no matter how long you run.
  • $E_0$ just above the barrier top: the particle crosses, but it slows almost to a stop on top of the barrier (where its kinetic energy $E_0 - V(0)$ is small), so each crossing takes a long time.
  • $E_0$ well above the barrier: the particle sweeps back and forth across both wells; the phase-space orbit becomes one large loop enclosing both minima.
  • With the default start point, $x_0 \approx -1.31$, the particle needs $v_0 \gtrsim 2.80$ to reach the top of the barrier — the panel shows this threshold as a readout.

For $a = 1$, $b = 4$ the minima are at $x = \pm\sqrt{2} \approx \pm 1.41$ with $V = -4$, and the barrier top is $V(0) = 0$. The particle starts with total energy $-3.80$ in the left well (NVE). Over the 10,000-step run it…

  1. crosses to the right well a few times
  2. never leaves the left well
  3. slowly drifts to the right well because of integration error
Energy is conserved, and $-3.80 < 0 = V(0)$, so the barrier top is energetically forbidden. Velocity Verlet keeps the energy error tiny (far below the 3.80 deficit), so no spurious crossings occur.

Going further: thermal barrier hopping (NVT double well)

The double-well run above is NVE. The closing remarks point to the obvious next experiment: put the double well in contact with a Langevin heat bath, exactly as in Lesson 2. Now the energy is no longer fixed — random kicks occasionally pile up enough energy to carry the particle over the barrier. How often that happens depends on the ratio $E_{\rm barrier}/k_BT$, and over a long run the position histogram approaches the Boltzmann distribution $P(x) \propto e^{-V(x)/k_BT}$.

Why this matters

Each hop is a rare event: the waiting time grows roughly like $e^{E_{\rm barrier}/k_BT}$. Doubling the barrier (or halving the temperature) does not double the waiting time — it multiplies it by a large exponential factor. This is the sampling problem that Module 5 takes on.

📝 Key Takeaways

  • A Harmonic Potential represents stable chemical bonds and small oscillations, keeping particles confined.
  • A Double-Well Potential introduces metastability, representing a chemical reaction or conformation change with two states separated by a barrier.
  • The Langevin Thermostat balances a friction force with random stochastic kicks to control the temperature of the system (NVT ensemble).
  • Over a long simulation, the probability of finding a particle at a particular position is proportional to its Boltzmann weight, $P(x) \propto e^{-V(x)/kT}$.
