# Workspace instructions

- Create files and directories only inside this working directory; use `./tmp/` when temporary storage is needed.
- Do not delete files unless the user explicitly requests it.
- Maintain `PLAN.md` for task planning.
- Append timestamped steps and their reasoning to `LOG.md`; never remove existing log entries.
- Keep files organized and provide a README for each folder created or changed during a task.
